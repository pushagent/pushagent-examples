# Push Agent examples

Copy-paste examples for **[Push Agent](https://pushagent.net)**: web push notifications for any website, with no Firebase.

| Folder | What's inside |
|---|---|
| [`embed/`](embed) | Add Push Agent to any HTTPS website with one line of code and one small file |
| [`api/`](api) | Send notifications from your own code with the REST API: cURL, PHP, Node.js and Python, plus a dashboard alert you can run with cron |

Using WordPress or Joomla? The plugins do the setup for you:
- [pushagent-wordpress](https://github.com/pushagent/pushagent-wordpress): web push plus WooCommerce order-status notifications
- [pushagent-joomla](https://github.com/pushagent/pushagent-joomla)

## Quick start

1. Create a free account at [app.pushagent.net](https://app.pushagent.net) and add your website.
2. Follow [`embed/`](embed) to start collecting subscribers.
3. Send notifications from the dashboard, or from your code with the examples in [`api/`](api) (Growth plan).
